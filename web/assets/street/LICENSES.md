# Street 3D models: licences

Every file here comes from one of five Kenney packs, created and distributed by Kenney (www.kenney.nl), downloaded 2026-11-15 from kenney.nl. Files copied unchanged from the packs' GLB folders. Each pack's License.txt states Creative Commons Zero (CC0 1.0): http://creativecommons.org/publicdomain/zero/1.0/

Layout: one subfolder per pack, because the four City/Car kits each ship a different `Textures/colormap.png` that every GLB references by the same relative path. The textures are copied unchanged next to each pack's GLBs (Nature Kit GLBs use no external image). Each `<pack>/Textures/colormap.png` is the pack's own file and is covered by the same CC0 licence.
